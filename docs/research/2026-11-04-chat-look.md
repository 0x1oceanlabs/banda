# The chat's look: Banda's Thread Pane against Claude, Codex, Cowork and Work

- **Why:** Roma likes how Banda's chat works and asked on 2026-11-04 to go
  through every element and bring it under one style and design concept,
  "a beautiful, elegant chat that is pleasant to work in", taking the best
  from Claude, Codex, Cowork and Work.
- **Banda:** `origin/main` at `9e803a15`, rendered in a browser.
- **Others:** screenshots from GitHub issues, vendor docs and videos, read
  on 2026-11-04. Nobody signed in to any product.
- **Marks:** **V** = seen in a render or a screenshot. **I** = inferred.

## 1. How it was looked at

**Banda (V).** The real `ThreadPane` was mounted on a fake `Engine` in a
throwaway page served from `app/web`, at 760px, light and dark. One long
fixture Thread covers a Person message with an image, a thought, reads,
searches, a failing and a passing test run, edits with diffs, a reply with
headings, lists, code, a table, Mermaid, a quote, a link and math, a
changed-files card, a stop, a proposed plan, a failed turn with an Issue,
a turn asked by another Thread with a todo plan, a permission Question,
and a queued message. Single components were rendered in the states the
Thread doesn't reach. Sizes are `getComputedStyle` values, not class names.

**Others (V, with limits).** Five views, two apps:

- **Claude** (claude.ai and the desktop Chat tab) and **Claude Code**'s
  desktop and web views.
- **Claude Cowork**, merged into Claude on 2026-09-16.
- **Codex**, the ChatGPT desktop app's Codex view since 2026-07-09.
- **ChatGPT Work**, OpenAI's agent mode in ChatGPT, launched 2026-07-09
  with GPT-5.6. Read as Roma's "Work": each vendor's coding product paired
  with its office-work agent (Claude Code and Cowork, Codex and Work).

Real captures come from issues on `anthropics/claude-code` (e.g. #98061,
#99870, #102136, #104529, #106761) and `openai/codex` (e.g. #45959, #48821,
#49928, #53179, #57828), plus Zapier's review of Work (2026-08-19). Some
Work and Cowork images are staged vendor renders. Pixel sizes and colours
are estimates.

## 2. Banda today (V)

The chat works; its parts don't share one set of values.

| Value | In use |
|---|---|
| Type sizes | 6, 8 counting mono: markdown h2 **24**, h3 **20**, body 14, `sm` buttons 12.8, `xs` 12, and tool text at **16** by accident (`ui/trace.tsx:141` sets no size, so `ToolCall`'s text inherits the root) |
| Radii | 6: 4 (inline code), 8, 10 (composer, tables), 14 (cards, code blocks), 18 (the Person's bubble; the same bubble queued is 14), full |
| Surfaces | 3 systems for "a block": Banda's cards (`bg-card`, `p-3`, 14), Streamdown's frames (`bg-sidebar`, a frame in a frame), console and diff (8, no padding) |
| Borders | 6 styles, shadows 4 recipes |
| Icons | 5 sizes, lucide at stroke 2 |
| Colour | `--attention`, the theme's signal colour, is never used in the chat; effort is coloured by the terminal palette (`--ansi-4/5`) |

What reads wrong, in short:

1. Headings in a reply are bigger than anything else in the Pane; in the
   proposed-plan card a 24px heading sits under the card's 14px title.
2. "Secondary information" has five styles (12 muted, 14 muted, 14 w500
   muted, 12 w500, mono 12).
3. What waits for the Person is the faintest row: a form Question's line
   and a tool waiting for permission are at 60% opacity.
4. A failed tool paints the whole line red; a command the Person stopped
   shows as failed; "You stopped after 8s" is followed by "Stopped.".
5. An opened fold, work line and tool draw up to four vertical rules (the
   work line two, 16px apart), and the work list scrolls inside the
   thread with its console and diff scrolling again inside it.
6. "Working for 45s" sits under the asking message, above everything the
   turn has done since.
7. Every message reserves an invisible 24px row for its hover actions:
   about 34px under each message against 16 between other rows.
8. The composer is radius 10 with 32 and 28px buttons; the drawer and
   "Plan ready" stacked on it are 14 with a shadow.
9. Mermaid in light uses its own lavender and purple. (Fixed on
   `feat/mermaid-card`: one card in the look's colours.)
10. The prompt's size follows the window (`text-base md:text-sm`), not the
    Pane, so the same Pane shows 16 or 14.

## 3. What the others share (V)

All five have settled on one skeleton:

- a centered reading column about 730px wide; no bubble or avatar for the
  Agent; the Person's message in a flat grey bubble on the right;
- one muted line per stretch of work, with a chevron, that opens to the
  calls;
- decisions (permission, plan, question) in a card docked at the composer
  or in its place, with key hints;
- model and effort as text under or in the composer, effort lighter;
- plans, reviews and files in a pane beside the chat.

The best single ideas, each from a real capture:

| Idea | From | Evidence |
|---|---|---|
| One line per turn with duration, counts and outcome: "Worked for 5m 20s", "ran 10 commands (2 failed) +46 −0" | Codex, Claude Code | codex#45959, claude-code#99870 |
| Opened, the log is plain past-tense rows; a failure is a red "Failed" tag, not a red row | Claude Code | claude-code#99870 |
| The live turn ticks "Working for…", and the current step shows its own time | Codex, Cowork | codex#53838, claude-code#62159 |
| A card per turn: "Edited 3 files +233 −273", folder dimmed, name bright, Review | Codex | codex#45959 |
| The permission sits on the composer: a plain question, the command in mono, "Deny Esc" and "Allow once ⏎" | Codex, Claude Code | codex#48821, claude-code#98061 |
| "Allow once" stays the main answer; making "Always allow" the default drew a regression report | Claude Code | claude-code#102136 |
| A question card with numbered choices and a last row "No, and tell it what to do differently" | Work, Codex | codex#57828 |
| While it runs, the composer says "Steer this thread…" and queues | Claude Code, Cowork | claude-code#98995 |
| Model and effort as one control, effort in a lighter grey | Codex, Claude Code, Work | codex#45959, claude-code#102218 |

To avoid, from users' complaints: a fixed narrow column (codex#54331), a
cramped scrolling thinking box (codex#49928), "Always allow" as the
default (claude-code#102136), an always-moving background on a new
thread (claude-code#102387).

## 4. Banda's own constraint (V)

Banda tiles. A new column is half the screen (`look.toml`,
`[columns] default = "1/2"`), Roma usually has two Agents side by side and
sometimes the sidebar, so a Thread Pane is often 500–850px wide, not the
others' fixed 730px column in a wide window. Type sized for a wide column
is too big in half a laptop screen.

## 5. Limits

- No first-hand use of the other products; captures are cropped, themed
  or in other languages, and sizes are read off pixels.
- Streaming, hover and transition timing were not seen in any product.
- In Banda the Visual's page, the Thread details card and the glass looks
  were not rendered.
