7 · Как поставляются Claude Code и Codex

Адаптеры едут внутри Banda, а сами CLI ставит человек.

Внутри Banda (AppImage / .app)

Окно и движок, как сейчас, плюс два адаптера, каждый одним файлом:

claude-agent-acp 0.99.1 · 2.2 MB
codex-acp 2.5.0 · 1.1 MB

Движок запускает их на Node, которая уже есть в Electron (ELECTRON_RUN_AS_NODE). Ни npx, ни Node на машине, ни сети при первом Thread не нужно. Версии обновляются вместе с Banda.

→
У человека

Свой claude и свой codex, со своим входом и своей подпиской. Обычно лежат в ~/.local/bin после официального установщика, иначе там, где их держит mise или brew.

Адаптеру передаём путь: CLAUDE_CODE_EXECUTABLE / CODEX_PATH

CLI обновляются сами, Banda только проверяет минимальную версию.
